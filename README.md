# 🌊 Surf - Modern Web Application

## 🚀 Overview
Surf is a modern, responsive web application designed to provide a smooth and engaging user experience. It features multiple pages including Home, Services, Booking, and more.

## ✨ Features
- Responsive design (mobile + desktop)
- Clean UI/UX
- Multi-page navigation
- Fast and optimized performance

## 🛠 Tech Stack
- React.js
- CSS
- Vite
